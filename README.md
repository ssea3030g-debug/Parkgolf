# 파크골프 수첩

할머니가 휴대폰으로 쓰는 파크골프 앱입니다. 큰 글씨·큰 버튼, 설치 없이 인터넷 주소로 열고 홈 화면에 추가해서 씁니다.
기록은 휴대폰 안에만 저장됩니다.

- **성적 기록·분석**: 대회·연습 성적을 넣으면 그날 날씨와 골프장 특징을 합쳐 잘한 점·보완점·연습 과제를 알려 줌
- **내기**: 점당 금액을 정하고 타수를 넣으면 자동 정산, 누가 누구에게 얼마 주는지 정리
- **골프장**: 검색, 지금 날씨·미세먼지·예보, 운영 상황 예상
- **일정**: 파크골프 일정만 관리, 삼성 캘린더에 넣기(.ics)
- 준비물 체크, 몸풀기 체조, 소리 읽기, 백업

| 폴더 | 내용 |
|---|---|
| [`app/`](app/README.md) | 앱 (HTML·JS, 서버 없이 동작). GitHub Pages 로 배포 |
| [`server/`](server/README.md) | (선택) 기상청 날씨·AI 코치 중계 서버. Cloudflare Workers 로 배포 |

## 올리는 순서 (휴대폰만으로 가능)
1. **앱**: 저장소 Settings → Pages → Source 를 **GitHub Actions** 로 → Actions 탭에서 **앱 배포** 실행 → 요약에 나온 주소를 할머니 폰에서 열기
2. **서버(선택)**: [`server/README.md`](server/README.md) 의 "컴퓨터 없이 휴대폰으로" 따라 하기 → 앱 설정 → 서버 연결에 주소와 비밀번호 넣기
